# Experiment results (KAN-41)

Open `/accuracy/experiments?workspace_id=<original-source-workspace-id>` or choose **Experiments** from the Accuracy navigation while a source workspace ID is in the URL. The page accepts an explicit source workspace ID. It fetches the read-only report from `GET /api/accuracy/experiments/results?source_workspace_id=<id>&format=json`. That endpoint requires sign-in and access to the original source workspace; unavailable or foreign sources return the same 404. The page does not enumerate workspace names.

The JSON and JSONL download links use that same authenticated endpoint. JSON contains the complete report. JSONL contains one complete comparison or standalone attempt per line, with raw retained evidence and repeat rationale. These exports may contain original prompts, outputs, evaluations and identifiers; handle them as source-workspace data.

Each comparison shows its status, identity, attribution reasons, mismatch reasons, retained attempts and calls. Pass tables show one-pass baseline and each candidate, followed by call/version outcomes, must-find recovery and loss, all found/partial/missed/wrong deltas from the previous version and V0, regressions, and measured cost and latency. Standalone extraction attempts remain **Descriptive** and show the same per-call version deltas and item outcomes where retained; their runtime, critic and judge events are also included in JSON and JSONL. Mixed tables show each candidate and attempt, final source outcomes, stage and gate status, selected/generated lineage, change rows, and explicit scored or unscored dimensions. Each source evaluation expands to retained item outcomes, including gold key, model index, status and reason; empty or unscored evaluations say so. Expandable raw evidence preserves exact inputs, outputs, critic and judge events, and the full retained comparison. **Unknown** means metering or evidence was unavailable; it is not a zero estimate.

Attribution is limited to curated **source-gold** outcomes. An **Observed gain** means one complete matched comparison improved exact recovery without a must-find loss, increased wrong/partial outcomes, or a retained serious regression. **Consistent improvement** requires at least two separately retained complete matched comparisons with disjoint attempts and calls, the same original documents, gold, evaluator, configuration and conditions, and a safe gain in every series member. Every repeat member remains linked, including neutral, failed, incomplete and unknown members that can prevent that label. An incomplete cohort with passes 1 and 2 also blocks the comparable three-pass series, even though pass 3 was never retained. A single observed gain is not consistency, statistical significance, production approval, or proof of whole-pipeline improvement. Downstream mixed dimensions without curated labels remain unscored; full-pipeline status is separate from source-gold gain.
