## Global Constraints

- PR targets `admin-accuracy-removal`, the parent branch, per explicit user instruction. Baseline 8708bbc9.
- No data disposal, retention deadlines, table drops, merging or deployment.
- No automatic record migration; existing tables and historical artifacts stay untouched.
- Development owns experiments/model decisions; AI & routing owns deployed behavior; Accuracy routes are retired.
- Never publish private source/artifact content or credentials. Mark unknown backup/access coverage as unverified, never invent evidence.
- Use an owned disposable PostgreSQL container, no shared database/server and no paid calls.
- Parent owns git commits, publication to both remotes, PR and Jira lifecycle.

## Review Focus

- Stale active documentation must not invite users to removed routes or destructive cleanup.

- Retention inventory must distinguish code-declared locations from operator-verified private holdings/backups.
- Rollback restores a consistent prior app and command/extraction paths against untouched schema; database restoration is separate and potentially destructive.
- Evidence must identify actual commands/results, limitations and owned resources, without claiming unrun checks passed.
