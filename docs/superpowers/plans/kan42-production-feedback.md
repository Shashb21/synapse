## Global Constraints
Feedback is append-only and belongs to an exact immutable assembly, historical approval review and successful downstream production consumer run in the same workspace. Derive contributor identity on the server. Only contributors write; authorized workspace readers read. Never modify assembly fingerprints, approvals, evaluations or gold metrics. Retrospective feedback survives supersession; successors have separate histories. Validate recorded JSON defensively and use the full recorded binding set to reconstruct consumed items using approvedLiveInventory projection rules. Human versions may have no extraction run. No paid provider calls. Use existing TypeScript/Vitest tests, TDD RED/GREEN evidence, typecheck, scoped ESLint and diff checks. Read relevant installed Next.js docs before Next.js edits. Workers never spawn agents or publish; commit only owned files. Preserve others' changes.
