## Known direction (locked)

| Slide-native pattern | Digital Synapse pattern |
| --- | --- |
| One deck = whole story | **One workspace = one IEGP** with linked sources |
| Gap/tactic tables on slides | **Card surfaces** with provenance expand; status chips Open / Partial / Addressed |
| Static timeline graphic | **Interactive Gantt** as save-final truth (click activity → gap/tactic/deps) |
| Notes in speaker layer | **Audit trail**: run traces, edit rationales, quote validation |
| Mixed sources on one slide | **Per-source gold** in `reference/<slug>/gold/` — never mix tactics/gaps across files in eval |

## Improvements we will propose after PPTX analysis

1. **Progressive disclosure** — overview Gantt first; drill-down to coverage dimensions without slide-hopping.
2. **Miss flags queue** — completeness audit as a first-class inbox, not buried in appendix slides.
3. **Pairwise coverage review** — replace wide mapping tables with one gap↔tactic decision at a time + quote panel.
4. **Planning context drawer** — asset/indication questionnaire always visible during prioritization (not a hidden slide).
5. **Export** — Gantt PNG + audit JSON bundle for cross-functional meetings (replaces “email the deck”).
