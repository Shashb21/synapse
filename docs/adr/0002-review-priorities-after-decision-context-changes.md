# Review confirmed priorities after decision context changes

KAN-120 makes the affected decision and its timing explicit inputs to priority review. When those values or a gap's linked objective change, require review again for affected Open gaps while retaining their prior bands, scores, rationale and history; record the reason and show the impact before saving. This deliberately changes the existing behavior of retaining confirmation after context edits: it prevents old approval from appearing to endorse new circumstances, accepting that confirmed High gaps temporarily lose eligibility for new ideation until reviewed again; existing tactics and previously unlocked navigation remain available.

Changing the gap's Evidence needed statement also requires review; changing only its display name does not. A context editor may cause this review transition through an authorised edit, but assigning or confirming a replacement priority still requires prioritisation permission.
