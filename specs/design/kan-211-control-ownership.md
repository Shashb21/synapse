# KAN-211 control ownership inventory

Baseline: KAN-209, commit `5753c869`, on `admin-accuracy-removal`. This inventory follows actual writers and readers, rather than assuming that a setting affects customer execution because Accuracy displays it. **Live** means customer execution; **experiment** means a Development or legacy Accuracy run; **shared** means infrastructure or semantics used by both. **Retiring** describes the legacy surface; KAN-212 removes its endpoint and runtime while preserving its records.

No missing live control was confirmed. AI & routing already owns customer provider/model routing, ordered backups, temperature, token limits, module activation and AI switches. There is no existing live monetary budget control to relocate. Token limits bound individual model output; they are not a spending allowance. Experimental allowances and benchmark budgets stay in Development. KAN-211 made no production configuration changes, migration, endpoint retirement or data deletion; KAN-212 retires the endpoint and runtime without migrating or deleting data.
